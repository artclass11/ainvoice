# AInvoice early-access desktop release

This branch exists to build the first public desktop installer set from the shared AInvoice application.

## Scope

- Windows x64 installer
- macOS Apple Silicon and Intel disk images
- Linux AppImage / Debian / RPM bundles where supported by the runner

## Important

This is an early-access build. It is not a production-ready accounting or tax system. The PIN is an app-entry control, not encryption for live local storage. Exported backups are password encrypted; keep the password safe and verify restore before relying on a backup.

Desktop installers are currently unsigned unless platform signing is configured. Windows SmartScreen and macOS Gatekeeper warnings may appear. Do not bypass security warnings unless you have verified the release and publisher details.

Android and iOS signed packages are built in their separate workflows and require private signing credentials. They are not part of this desktop release.
